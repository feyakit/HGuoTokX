## 项目特点

HGuoX 是一套基于 **Tauri 2（Rust 后端）+ React 19 + TypeScript + Tailwind CSS 4** 构建的跨平台客户端，一套代码覆盖桌面端与移动端五大平台，围绕「流光玻璃视觉、零割裂追剧体验、复杂网络高可用」进行深度工程化打磨：

### 1. 五端一套代码与原生级启动体验
- **全平台覆盖**：支持 **iOS、Android（按 ABI 分包）、Windows（NSIS 安装包 + 便携版）、macOS（Universal DMG）、Linux（DEB）**。
- **移动端原生适配**：支持 Android Adaptive Icon、iOS / Android 深色防闪白原生启动页、安全区（`env(safe-area-inset-*)`）自适应与系统返回键栈管理（全屏态优先退出全屏）。
- **桌面端无边框工作台**：Windows / Linux 自定义无边框标题栏与边缘缩放热区、macOS 原生窗口融入、左侧可折叠导航栏与剧场停靠面板。

### 2. 双模式播放器与精细手势系统
- **⚡ 抖音模式（无限随机流）**：首页一键进入，支持全站多页随机洗牌、自动避重、平滑阻尼上下滑切集；点击「看全集」或左滑可无缝携带当前集数与秒级进度进入剧场模式。
- **🎬 剧场模式（沉浸追剧）**：完整剧场控台（进度条、快捷 `1x`–`2x` 倍速、下一集、选集抽屉、线路就地切换、横竖屏全屏与「适应 / 铺满」独立切换）、片尾 5 秒连播倒计时、全剧播完收尾交互与集数/秒级断点记忆续播。
- **手势与防误触**：支持单击暂停/继续、双击净屏、左右拖快进/快退、长按 `2.0x` 倍速（上滑锁定）/ `0.5x` 减速、双指捏合缩放与屏幕锁。

### 3. 莫比乌斯极光玻璃 UI 与封面氛围取色
- **封面实时取色**：自动提取当前剧集封面主色并计算暗调背景与多层氛围强调色，在播放页非视频区与剧集详情页顶部实时渲染专属氛围光晕。
- **内容编排与交互细节**：
  - **首页三态布局**：官方口碑推荐轮播展台（跟手拖拽 + 错峰避重）+ 热播 TOP 10 + 16:10 原创宽画幅 + 首发上新流 + 3D 领奖台热榜，支持触底自动加载、防连点导航去重与二级页返回保留原滚动位置。
  - **片库、发现与社区吃瓜**：2×2 Bento 玻璃分类磁贴、跨模块智能去重、一键「换一批」淘片刷新、专题策展合集与标签屏蔽；吃瓜社区支持「时间线 + 热议榜」双视图，自动区分黑料吃瓜与短剧剧评。
  - **性能与老内核兼容**：GPU 无过冲阻尼动画、只读接口内存缓存与并发去重、下集 HLS 播放列表预热，并内置构建期 CSS 兼容性检查（`check-legacy-css.mjs`）。

### 4. Rust 网络层：国内并发选线与复杂代理原生兼容
- **并发竞速自动选线**：主站探测（1 秒优先窗口）与发布页拉取并发执行，命中首个可用镜像后 350ms 早停收口；探测请求关闭重试退避、单节点超时收敛至 3 秒，发布页内置 5 分钟内存缓存。
- **复杂网络与代理兼容**：Rust 底层网络栈原生兼容主流代理工具 TUN FakeIP（`198.18.0.0/15` / `fdfe:dcba:9876::/48`）、运营商 5G NAT64（`64:ff9b::/96`）与 DoH 加密解析兜底，并支持播放页内就地切线与脱敏网络诊断复制。

## 技术栈与目录结构

| 层级 | 技术选型 |
| :--- | :--- |
| 跨平台壳 & 原生能力 | Rust · Tauri 2 · Tokio · Reqwest |
| 前端框架 & 播放内核 | React 19 · TypeScript 5 · Vite 7 · Tailwind CSS 4 · `hls.js` |
| 构建与质量校验 | `tsc` · `check-legacy-css.mjs` · Playwright 自动化测试脚本 |

```text
HGuoX/
├── src/                    # React 19 前端应用（页面、播放器、手势、状态与样式）
│   ├── components/         # EpisodePlayer、VideoSurface、面板、卡片与 iOS 风格控件
│   ├── pages/              # 首页、片库、吃瓜、发现、详情、榜单、搜索、个人中心、设置
│   ├── styles/             # 极光玻璃样式系统（shelf.css / ios.css）
│   └── autoLine.ts         # 自动选线策略与健康度调度
├── src-tauri/              # Rust / Tauri 2 原生核心（网络、并发选线、DoH、媒体传输、平台适配）
├── scripts/                # 版本对齐、图标生成、老内核 CSS 检查与自动化测试脚本
└── .github/workflows/      # CI 检查与五端全自动 Release 发布流水线
```

## 本地开发与构建

> 环境要求：Node.js 22+、pnpm 10+、Rust（stable）；如需构建桌面端或移动端原生包，需配置对应平台的 Tauri / Android SDK / Xcode 工具链。

```bash
# 1. 安装依赖
pnpm install --frozen-lockfile

# 2. 启动前端开发服务器 / Tauri 桌面端调试
pnpm dev
pnpm app:dev

# 3. 类型检查、生产构建与老内核 CSS 兼容性校验
pnpm build

# 4. 打包桌面端或 Android 安装包
pnpm app:build
pnpm android:build
```

常用自动化校验脚本（见 [package.json](package.json)）：

```bash
pnpm test:playback          # 播放器与播放链路检查
pnpm test:line-selection    # 自动选线策略测试
pnpm test:storage-migration # 存储键迁移测试
pnpm test:mobile-layout     # 移动端布局校验
```

## 升级与配置兼容

- **本地存储迁移**：本地收藏、观看记录、偏好与主题统一使用 `hguox_*` 存储键；首次启动会自动将同空间下的旧 `hghub_*` 数据平滑迁移至新键。
- **环境变量**：统一使用 `HGUOX_PROXY`、`HGUOX_STRICT`、`HGUOX_TEST_COVER_URL`、`HGUOX_TEST_MEDIA_URL`、`HGUOX_TEST_MEDIA_OUTPUT`（未设置时兼容回退 `HGHUB_*` 旧变量）。
