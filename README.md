# HGuoX

**跨平台短剧 / 漫剧客户端 · Rust + Tauri 2 + React 19**

iOS（`.ipa`）/ Android（`.apk`）/ Windows / macOS / Linux · 莫比乌斯极光玻璃设计 · 沉浸式竖屏连刷

</div>

## 核心特性与功能介绍

- **全平台一套代码**：基于 Rust + Tauri 2 + React 19 构建，同时覆盖 **iOS、Android、Windows、macOS、Linux** 五端，支持 Android Adaptive Icon 与 iOS / Android 深色防闪白原生启动页。
- **双模式播放体验**：
  - **⚡ 抖音模式（无限随机流）**：首页顶栏一键进入，全站多页随机洗牌、无限连刷且自动避重与断线重试；底部与剧场模式统一，提供进度条、快捷倍速、就地切线与平滑阻尼切集动画，全屏按钮收纳至右侧社交栏；点击「看全集」或左滑直接带着当前集数与进度秒数进入剧场播放。
  - **🎬 普通剧场模式（沉浸追剧）**：从剧集详情、历史、分类、搜索或专题进入，提供完整剧场控台（进度条、快捷 `1x`–`2x` 倍速、下一集、选集抽屉、线路就地切换、横屏/伪横屏全屏）、片尾 5 秒连播倒计时提示、全剧播完收尾提示（重播 / 第 1 集 / 下一部）与集数/秒级断点记忆续播。
- **精细手势与防误触系统**：
  - 支持单击暂停/继续、双击沉浸净屏、左右拖快进/快退、长按 `2.0x` 倍速（上滑锁定）/ `0.5x` 减速、双指捏合缩放、屏幕锁防误触，以及全屏态下硬件/系统返回键优先退出全屏。
- **封面取色氛围系统**：
  - 自动提取当前剧集封面主色并计算暗调背景与多层氛围强调色，在播放页非视频区与剧集详情页顶部实时渲染专属氛围光晕。
- **差异化内容编排与流光玻璃 UI**：
  - **首页三态体验**：官方口碑推荐榜主推展台（错峰避重）+ 热播风向标 TOP 10 + 16:10 宽画幅原创 + 时间轴首发上新流 + 金银铜 3D 领奖台热榜，支持触底自动加载。
  - **片库、发现与社区吃瓜**：2×2 Bento 玻璃色彩分类磁贴、跨模块智能去重、一键「换一批」淘片刷新、专题策展合集与标签内容偏好屏蔽；吃瓜社区采用「时间线（按日期分组）+ 热议榜」双视图，分类对齐官网（黑料吃瓜 / 短剧剧评）并自动去重，桌面端同步提供侧边栏入口。
  - **个人中心与同步**：「我的」统一流光毛玻璃卡片界面，支持账号云端同步、短剧与吃瓜浏览历史断点记录、短剧/吃瓜双栏收藏（支持一键连刷全部未屏蔽收藏）与创作者空间。
- **复杂网络与代理兼容**：支持多线路自动测速优选与播放页内就地切线，Rust 网络层原生兼容主流代理工具 TUN FakeIP（`198.18.0.0/15` / `fdfe:dcba:9876::/48`）、运营商 5G NAT64（`64:ff9b::/96`）与 DoH 加密解析兜底。
