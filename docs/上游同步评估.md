基线：`git log main..upstream/main`，上游 `a7d22db`（v2.2.0 收尾），共 **38 个提交**。
口径：**只看功能修复，UI/文案/目录重构一律不动**（用户定的）。我们的树在上游模块化重构
（`src/features/*`、`src-tauri/src/{api,net,lines}/`）之前分叉，所以上游的 Rust 提交**不能 cherry-pick，
只能按行为手搬**。
