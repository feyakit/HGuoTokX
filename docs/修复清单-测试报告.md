## 未修的四条（5 / 7 / 8 / 9）+ 两条待复核（6 / 17）

- 5、7 是新增交互能力（字幕安全区、轮播手势），改动面比修 bug 大，留待确认后再做。
- 8、9 需要先查数据层（历史写入条件、热搜排序字段），不在本轮盲改。
- 6 上游已确认支持 `is_original`，需要新包真机再点一次确认是否仍复现。
- 17 涉及屏幕方向，需引入 Tauri 方向插件或 Web Fullscreen + orientation.lock（Chrome 87 支持有限）。
