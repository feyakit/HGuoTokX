# HGuoX 设计语言 v1（Apple Music 式环境光 + Liquid Glass）

> 一句话：**界面的颜色永远来自内容本身，界面的材质永远模拟玻璃。**

## 一、三条原则

1. **内容驱动（Content-driven color）**
   每个界面的强调色 = 当前内容（剧集封面）的主色，经对比度钳制后使用。
   没有内容上下文时（搜索空态、设置页）沿用最近一次取色，不随机、不重置。

2. **玻璃分层（Material hierarchy）**
   只用三种材质，不再增加：
   - **Clear glass**：压在有画面的地方（播放页底栏、浮动控件）
   - **Regular glass**：压在纯色底上的卡片、弹窗、分组
   - **Opaque surface**：文字密集区（设置列表、条款正文），保证可读优先
   判断标准：**背后有东西可透 → 玻璃；背后是纯色 → 干脆用实色。**

3. **克制动效（Motion with purpose）**
   动效只做三件事：状态切换（淡入淡出）、层级展开（弹窗/面板）、环境呼吸（沉浸背景）。
   统一 220–420ms，弹簧曲线 `cubic-bezier(.34,1.56,.64,1)`，全部尊重 `prefers-reduced-motion`。

## 二、Token 体系

| Token | 来源 | 用途 |
|---|---|---|
| `--accent` | clampAccent(封面主色, 4.5) | 主按钮、选中态、进度、焦点环 |
| `--accent-on` | 自动黑/白 | accent 上的文字与图标 |
| `--accent-deep` | 主色相 + l=0.12 | 沉浸背景底部、深色衬底 |
| `--accent-second` | 色相差 ≥40° 的次主色 | 次要强调、标签、图表第二色 |
| `--ambient-image` | 封面 64px 缩图 | 沉浸背景（模糊底） |
| `--glass-bg` / `--glass-edge` / `--glass-shine` | 主题固定 | 玻璃三层（已存在） |
| `--sab` / `--sat` | 系统安全区 | 底部/顶部留白 |

**禁止**：在业务代码里硬编码颜色（`#fff`、`rgba(...)` 直接写在组件上）。

## 三、逐页方案

| 页面 | 背景 | 材质 | 强调色落点 |
|---|---|---|---|
| **首页 · 刷剧流** | 视频满屏（无背景层） | Clear glass 底栏 + 右侧操作条 | 进度条、剧名竖条、点赞激活态 |
| **首页 · 非满屏** | 沉浸背景（封面模糊 + 着色 + 压暗 + 呼吸） | Clear glass | 同上 |
| **剧集页 / 详情** | 顶 40% 沉浸背景，向下渐隐到 canvas | 封面卡片浮起（regular glass + 阴影） | 播放按钮实心 accent、集数选中态 |
| **搜索** | 无图 → canvas + accent 8% 角部浸染 | 搜索框 regular glass；结果卡片实色 | 光标、清空按钮、命中高亮 |
| **分类 / 榜单** | 同上，列表首屏可带封面墙浸染 12% | 卡片实色 + 1px hairline | 排序选中、评分徽章 |
| **我的** | 已登录头像主色 → 12~18% 浸染 | 分组卡 regular glass | 开关、进度环 |
| **设置** | **纯 canvas，不加浸染** | 分组实色（Opaque surface） | 仅开关与选中项用 accent |
| **登录 / 弹窗 / Toast** | 背后内容模糊（backdrop） | Regular glass + 1px 高光边 | 主按钮实心 accent |
| **骨架屏** | 继承页面背景 | 骨架块 8% 白，accent 8% 微光扫过 | 无 |
| **TV 版** | 保持独立（大屏、遥控焦点） | 焦点环用 accent，不做沉浸背景 | 焦点环、选中卡片描边 |

## 四、沉浸背景规格（唯一实现，复用到所有页）

```
层 1  封面缩到 64px 宽 → background-size: cover 铺满（放大即模糊）
层 2  accent 20~25% 乘色
层 3  底部 40% 渐变到 #0E0F13
层 4  brightness 0.45~0.55 · saturate 1.6~1.8
动效  transform: scale(1.06 → 1.12)，18~24s ease-in-out 循环
切换  换剧时双层 0.5s 交叉淡入，禁闪黑
约束  仅当有黑边 / 需要背景时渲染；满屏时 display:none
```

性能红线（小米9 / Chrome 87）：**不放大图 + blur**，只用小图放大；动画只动 `transform`；单页沉浸层不超过 1 个。

## 五、分期落地

**P0（本周，跟着当前分支走）**
1. Token 层接管：accent → `--p-primary` / `--p-on-primary` / `--p-pc` / `--p-glow`
2. 播放页沉浸背景（Apple Music 规格）
3. 底栏选中胶囊接 accent
4. 去掉条款页闸门

**P1（下一版）**
5. 剧集页：顶部沉浸 + 封面卡片浮起
6. 搜索 / 分类 / 我的：浸染强度分档（8% / 12% / 18%）
7. 设置页：改实色分组，去掉浸染（可读优先）
8. 弹窗 / Toast / 骨架屏统一到新材质

**P2（可选）**
9. 取色开关（跟随封面色 / 固定主题色）
10. 沉浸背景的淡入式转场（剧集页 → 播放页连续感）
11. TV 版焦点态配色对齐

## 六、验收标准

- 任意页面截图，**强调色 100% 来自封面**（不允许出现硬编码蓝 `#74b7ff` 之类残留）
- 所有文字对比度 ≥ 4.5:1（用像素采样验证，不靠肉眼）
- 小米9 上滚动帧率不掉：`dumpsys gfxinfo` 无长帧堆积
- 换剧不闪黑、不残留上一部剧的颜色
- 浅色主题下不出现原色 accent 压白底（用 deep 变体）

## 七、风险

| 风险 | 对策 |
|---|---|
| 封面质量参差导致界面时好时坏 | clamp 只保对比度，另加"低饱和封面 → 用 second 色相 + 更高明度"的兜底 |
| 全站跟色后用户觉得晃 | P2 的取色开关；设置页不跟色 |
| 老 WebView 降级 | `@supports` 分档；沉浸背景不可用时退回纯 canvas |
| 与将来品牌色冲突 | 用 accent 覆盖的是"强调色"，品牌标识（图标/字标）不跟色 |
