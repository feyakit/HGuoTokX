## HGuoX 3.1.0

这一版把「颜色」整件事重做了一遍：界面的强调色不再写死，而是跟着当前这部剧的封面走。

### 封面色驱动

- 每部剧取一次封面主色，钳制到可读对比度后铺成全站强调色：底栏选中胶囊、进度条、
  按钮、开关、焦点环都跟着变；换剧才换色，同一部剧换集不变色。
- 深色主题直接用封面色，浅色主题自动换成同色相的深变体，避免亮色压白底。
- 冷启动先沿用上次取到的那套色，首页没出封面时也不会突然退回品牌紫。

### 沉浸背景

- 视频不满屏（有留白）时，四周不再是黑边：封面缩成小图放大铺满 + 封面色着色 +
  底部渐暗，并以 20 秒周期缓慢呼吸；满屏播放不渲染这一层。
- 剧集详情面板顶部 40% 同样铺沉浸背景，向下渐隐成页面底色；封面卡片浮在背景上。

### 页面浸染分档

- 播放页 35%（沿用），我的 18%，分类/榜单 12%，搜索 8%（只走左上角），设置页不跟色。

### 其他

- 首启不再弹出「使用条款与免责声明」，启动动画结束直接进首页。
- 骨架屏用封面色 8% 的微光扫过。

### 已知问题

- 系统 WebView 低于 Chrome 88 的设备（如未升级的小米9 出厂版本），底栏点击后
  页面可能不切换。建议在应用商店或系统设置里更新 Android System WebView 后再使用。
