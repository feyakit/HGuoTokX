# HGuoX 3.0.7

> 这一版没有新功能堆砌，主要是把上一轮测试报出的问题全部收口，并把播放器、设置页、按钮体系和数据新鲜度做了一次统一。

## 播放器

- **全屏崩溃修复（P0）**：安卓全屏改用 Kotlin 插件调 `setRequestedOrientation`，Rust 侧不再有任何裸 JNI；点全屏不再 `SIGABRT`，系统真转横屏，退全屏 / 退出播放器 / 切后台三条路径都回竖屏，播放进度不丢。
- **iOS 全屏三处根因**：不再走 HTML5 `requestFullscreen`（那条 "tauri://localhost is in full screen" 系统提示的来源）；修掉「只占半屏」的几何错误；iOS 16+ 走 `UIWindowScene.requestGeometryUpdateWithPreferences`，拿不到时静默降级。
- **播放页纯黑**：移除三层氛围取色，视频之外的区域（信箱区、安全区、标题栏背后）统一 `#000`，修掉「上边不黑下边黑」。
- **双击分区改三分法**：左 1/3 退 5 秒、中 1/3 播放/暂停、右 1/3 进 5 秒（原来是左右对半、步长 10 秒，中间区域容易误触）。
- **全屏禁用左缘返回**：全屏/伪横屏/真横屏下，从屏幕左缘往右滑不再误退全屏，改为正常 seek。
- **手势判定抽成纯函数层**（`src/playerGestures.ts`）：死区 10px、方向锁 1.4、seek 三档量纲、边缘返回、双击窗口、换集门槛 40%/70%、旋转冷却 300ms，全部有单测。
- **播放地址不缓存**：每次进集重新请求 `api_play`；403/404 自动重取一次再重试（CDN token 会过期）。

## 界面

- **设置页重做**：删掉顶部三个重复的圆形入口与六张折叠卡，改成 7 组平铺 15 行；删掉组右侧 badge 与页面底部重复的版本页脚；右侧控件按类型分三种（Switch / 当前值 + › / 仅 ›）。
- **退出登录移入设置**：「我的」页只保留账号展示（头像 / ID / 统计 / 收藏 / 关注 / 最近观看），底部退出登录块与版本页脚移除；设置新增「账号」组，只有一行退出登录（风险色 + 二次确认）。
- **全站按钮统一到品牌渐变**：`#7C5CFF → #5B6BFF` + 1px 白内描边，主 CTA 高 44 / 圆角 12 / 13·600；旧的橘→紫渐变全站清除；圆形图标按钮视觉 36、热区 44；所有主行动按钮补上按下反馈。
- **卡片圆角收敛到三档**：大容器/浮层 20、普通卡片/列表行 16、chip/胶囊 999。
- **顶栏 tab 热区补到 44**（视觉高度不变）。
- **抖音模式入口重做**：品牌强调胶囊，高 32 / 全圆角 / 内联 SVG 闪电 / 热区 44。

## 动效

- 新增统一 motion token（`--dur-1/2/3` + `--ease-out/in`）。
- 页面进入/返回双向转场（150–180ms），播放器退出 FLIP 缩回封面，退出全屏对称 FLIP。
- 图片淡入、列表追加 stagger、面板 220ms、toast 滑入、开关滑块、tab 指示条 FLIP、点赞心形、错误行展开等 14 类状态过渡统一。
- `prefers-reduced-motion` 下全部归零；低端机只保留按压反馈。

## 数据新鲜度

- 修复「同一个 tab 一辈子只拉一次」（`loadedKey` 闸门）与「SWR 后台刷新结果没有回填页面」两个根因。
- 列表页 TTL 收紧：首页 15s、分类/榜单 30s、吃瓜 30s。
- **下拉刷新**：首页三 tab、吃瓜、分类、榜单四处；刷新强制绕过全部缓存，成功提示「已同步官网」，失败保留旧数据。
- 回前台超过 30s 静默刷新当前页；前台每 5 分钟静默刷新列表页。
- 详情页与搜索结果页不做下拉（单条内容/关键词结果没有"新内容"概念），改为进页 SWR + 播放前重取地址 / 结果过期自动重搜。

## 线路

- **线路自愈**：DoH 优先解析、发布页候选先到先用、镜像列表落盘兜底、内置种子候选；上游换域名族或发布页被墙时仍能自动选到可用镜像。
- 落盘缓存只用于游客浏览的自动切线，**不授予登录凭据信任**（`trusted_auth_origin` 规则不变）。
- 发布页扫描只认 `https://host` 与站根 `xxx.cc/`，避免把注释里的裸域名当镜像。

## 性能

- 入口 JS 从 1.03MB 砍到 405KB（hls.js 单独成 chunk，播放器代码 lazy）。
- 启动动画期间就开始拉首页数据（动画本身未改），首屏封面就位 3694ms → 884ms。
- 长列表窗口化，首页追加下一批 231ms → 20ms。

## 已知限制

- 国内网络对主站存在 SNI 阻断，`huangguoai.com` 不可直连，只能走镜像；应用侧已做自愈，但无法绕过网络层阻断。
- 上游 `api_play` 只提供 `streams.main` / `streams.hevc` 两条流，没有分辨率分档，所以「画质」只能在有 HEVC 流时切换。
- 评论没有删除接口（应用与官网均无），发出的评论无法撤回。
- 小米九等 MIUI 机型可能把应用冻结成 `enabled=3`，`pm enable` 只顶几秒，需 `adb install -r` 重装。
