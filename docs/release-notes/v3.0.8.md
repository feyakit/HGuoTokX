# HGuoX 3.0.8

> 这一版没有新板块，全部是**播放页的收口**：宽画幅信箱区、结束态、选集/详情入口、竖滑手势、控件形态，外加 iOS 吃瓜列表的图片闪烁。

## 播放页 · 信箱区（宽画幅上下黑边）

- **黑边不再是纯黑**：宽画幅片源在竖屏 contain 时，上下黑边用本剧封面放大虚化（`blur(28px)` + `brightness(.55)`）垫底，封面未到或 404 时用深灰 `#14141c` 兜底，不再看起来像"没做"。
- **判定改成按 fit 实测**：只有 contain 且画面比与容器比相差 >2% 才铺虚化；竖版源竖屏走 cover（铺满无黑边）不铺，竖版源进横屏全屏铺左右黑边。
- **修掉三个 P0**：
  - 横屏全屏视频被黑渐隐盖掉一半 —— 删掉挂在视频包裹层上的上下 56px 渐隐（16:9 在 393 宽下只有 221px 高，两层各吃 56px 就只剩一条窄带）；
  - 视频被虚化层/黑底盖住 —— 虚化层改为用 poster 直接做 `background-image`（不再嵌 `<Img>` 被 `.player-root .ios-image` 的黑底压死），并统一正 z 序 + `isolation:isolate`；
  - letterbox 判定写反（`containerRatio > videoRatio*1.02`）导致竖屏宽画幅完全不铺 —— 改为按 fit 与比例差判定。
- **删死代码**：已无挂载点的 ambient canvas、空转的 220ms `setInterval` 一并移除。

## 播放页 · 结束态

- **本剧看完不再自动滑进下一部**：改为「本剧已看完」卡片 + 推荐 3 部，由用户自己选。
- 结束态按钮重做：主行动独占一行，换一批降级为文字链，推荐区轴线对齐；旧的「已播完全剧 / 重播 / ×」浮层拆掉，只留这一张卡。

## 播放页 · 入口与命中

- **选集入口永远在**：详情接口没回来、该剧没分集数据时不再整行消失；集数为空显示「选集」，点进去面板说明「集数暂未取到」并给「重试」。
- **命中加固**：信息栏那一行提到 `z-30` 并显式 `pointer-events:auto`；信息栏、选集、详情三处加 `data-hg-control` 标记（`meta-bar` / `episodes-entry` / `detail-entry`），点击日志带坐标。
- **clean 态拦截层（防点穿）**：控件收起时底栏不在 DOM 里，那块坐标上是可点内容 —— 真机上点信息栏会跳到别的剧。现在铺一层透明的 `clean-catcher`，只做唤起控件，绝不把点击交给下层。

## 播放页 · 手势与控件

- **竖滑被浏览器吞成点击**：`touchmove` 只拦「从舞台起手」的手势，其余交回页面滚动。
- 上下滑边界按剧判定；倍速跟着控件一起隐藏、恢复底层色；seek 精度与气泡避让；控件去胶囊、做小；新增「上一集」；无独立 HEVC 流时画质入口置灰显示「标准」。
- **底栏改「全浮」纯文字**：无底、无边框、无分隔线、无 blur，段间 14px 间距，12/600 纯白 + 双层 text-shadow，热区仍 44；压光（scrim）改比例型，并与控件一起显隐。

## iOS

- **吃瓜列表滚动时封面闪**：从滚动路径移除 `backdrop-filter`；去掉 `.ios-image` 上的 `translateZ(0)` / `backface-visibility`（长列表里反而让 WKWebView 反复重建合成层）；`shimmer` 改静态骨架不再无限循环；加载完成后不再有 opacity 过渡。本地 WebKit mock **未能复现**，本版是逐条加固，需要真机确认。
- 滚动期动效闸门，抑制 iOS 整页闪。
- 恢复 iOS 图片 lazy 加载与加载后淡入（回退上一版过度改动）。

## 播放稳定性

- 单集黑屏自动切流兜底（并修掉切流闭包过期导致兜底不生效的问题）。

## 已知限制

- 上游 `api_play` 只提供 `streams.main` / `streams.hevc` 两条流，没有分辨率分档，「画质」只能在本集真有 HEVC 流时切换。
- 国内网络对主站存在 SNI 阻断，只能走镜像；应用侧已做自愈，绕不过网络层。
- 评论没有删除接口（应用与官网均无），发出的评论无法撤回。
- 小米九等 MIUI 机型可能把应用冻结成 `enabled=3`，`pm enable` 只顶几秒，需 `adb install -r` 重装。
- iOS 吃瓜闪在本机 mock 下不复现，本版为加固处理，需 iPhone 真机复验。
