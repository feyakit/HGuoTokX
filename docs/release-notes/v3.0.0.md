## HGuoX 3.0.0

### 更新点

- **播放器双模式统一与交互增强**：
  - 抖音模式与剧场模式统一底部控台布局，补齐就地切线、平滑阻尼切集动画，并将全屏按钮收纳至右侧操作栏。
  - 抖音模式点击「看全集」或左滑可直接带着当前集数与播放秒数进入剧场播放；清晰度切换支持自动记忆并恢复当前播放进度。
  - 剧场模式新增全剧播完收尾提示（支持「重播」「第 1 集」「下一部」或「看推荐」）。
- **吃瓜社区重做（时间线 + 官网对齐）**：
  - 新增「时间线」与「热议榜」双视图：时间线按日期分组展示，搭配精选头条、图文快讯与纯文短讯多种卡片形态。
  - 分类精简并与官网对齐为「全部 / 黑料吃瓜 / 短剧剧评」，并按帖子 ID 与标题去重，避免重复内容。
  - 补齐桌面端侧边栏「吃瓜」导航入口，并在「我的」页面新增吃瓜浏览历史记录。
- **触底自动加载与封面取色**：
  - 首页、发现、分类与吃瓜列表补齐触底自动加载更多，减少手动翻页。
  - 增强封面取色氛围系统：优化暗调背景明度与多层径向光晕，修复详情页封面跨域取色回落默认色的问题。

### 修复点

- 修复抖音模式残留序号徽章、画质按钮重复文案及切集/切画质后进度丢失问题。
- 修复吃瓜精选卡片标签重复展示及列表内容重复问题。
- 修复播放页与详情页封面氛围取色差异不明显的问题。
