## HGuoX 3.0.0

版本号从 3.0.0 重新起算，这一版主要是改名加上游同步。

### 改名

- 项目改名为 **HGuoX**，仓库地址 `github.com/feyakit/HGuoX`（旧地址会自动跳转）。
- 应用标识符改为 `com.hguox.app`。Android / iOS 会将使用不同标识的安装视为独立应用。安装测试包前请保留旧安装，并确认已备份可导出的数据。卸载会清除旧安装本地数据。
- 存储键（`hghubx_*`）和环境变量（`HGHUBX_*`）沿用原名。键迁移仅适用于当前应用存储空间，登录状态、收藏和历史的跨包迁移仍需验证。

### 同步上游 HGhubX 2.1.2

- 标签详情页同时展示短剧和吃瓜帖子，各自独立分页；标签热度单独标注，不再和内容
  数量混在一起。
- 横屏视频按当前播放源的媒体尺寸识别，尺寸确认前按完整画面适配。
- 修复社区标签只查询短剧接口、导致官网有帖子而应用显示空列表的问题。
- 修复切集 / 切源时媒体尺寸报告竞态，避免首页横屏视频被裁切或没有横屏控制。
