## HGuoX 3.0.0

版本号从 3.0.0 重新起算，这一版主要是改名加上游同步。

### 改名

- 项目由 HGuoTokX 改名为 **HGuoX**，仓库地址 `github.com/feyakit/HGuoX`（旧地址会自动跳转）。
- 应用标识符改为 `com.hguox.app`。Android / iOS 会把这一版当成**另一个应用**：
  装新版前请先卸载旧版。旧的登录状态、收藏、历史不会自动带过来，它们留在旧包的
  数据目录里，卸载即清除。
- 存储键（`hghubx_*`）和环境变量（`HGHUBX_*`）保持不变，升级迁移逻辑不受影响。

### 同步上游 HGhubX 2.1.2

- 标签详情页同时展示短剧和吃瓜帖子，各自独立分页；标签热度单独标注，不再和内容
  数量混在一起。
- 横屏视频按当前播放源的媒体尺寸识别，尺寸确认前按完整画面适配。
- 修复社区标签只查询短剧接口、导致官网有帖子而应用显示空列表的问题。
- 修复切集 / 切源时媒体尺寸报告竞态，避免首页横屏视频被裁切或没有横屏控制。
