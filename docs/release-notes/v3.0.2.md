# HGuoX v3.0.2

## 网络与自动选线
- 优化国内网络自动切换速度：主站探测与镜像发布页拉取改为并发竞速（主站 1 秒优先窗口），命中首个可用镜像后 350ms 早停收口，探测专用请求关闭 3 次重试退避，单节点超时收敛至 3 秒
- 发布页增加 5 分钟内存缓存，业务接口连续失败后立即升级自动选线

## 体验与界面修复
- 分类页「# 标签库」改为直接进入独立标签库子页，并放大触控热区
- 导航栈增加同页防连点去重，避免快速连点叠出多层相同详情页
- 修复详情页底部 CTA 压住选集 6–10、评论输入栏与播放器底栏安全区留白不足、我的页版本号被底栏遮挡的问题
- 统一轮播指示点、完整榜单、排序胶囊、换一批、抖音模式及播放器右栏按钮的 44×44 触控热区
- 修复专题页标题与分类 2×2 磁贴副标题截断、最近观看进播放器标题显示「继续观看」、横屏播放器控制栏重叠、榜单缺少到底收尾提示等问题
- 首页自动触底加载分栏移除漂移的「加载更多」按钮，上新横幅计数文案调整为「已加载 N 部」，设置页未开放外观选项增加明确禁用态
