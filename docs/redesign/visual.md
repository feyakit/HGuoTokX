# 视觉

手机端集中在 `src/styles/v3.css`，只作用在 `.v3-app`（`MobileShell`）。桌面不套这层。

| Token | 值 | 用途 |
|---|---|---|
| `--v3-ink` | `#1a120e` | 页面最深处 |
| `--v3-ember` | `#f0a36a` | 指示、小标题 |
| `--v3-paper` | `#fff4e6` | 主文字 |
| `--v3-mute` | `#d9c7b4` | 次文字 |
| `--v3-card` | `rgba(62, 42, 32, 0.78)` | 卡片 |

背景是暖棕渐变加顶部光晕，不是纯黑。封面取色继续叠在刷剧晕染、看全集、标签、剧场顶部和信息卡上。

字号沿用系统无衬线。页标题收紧字距。设置入口是通栏列表，不再是四个挤在一起的图标。底栏是暖色毛玻璃，选中字用 `#fff4e6`，未选中 `#d9c7b4`，指示条用 ember。刷剧时底栏透明度 0.46。

圆角：入口卡 16，列表和账号卡 18，侧栏胶囊 28。动效沿用原来的淡出和取色过渡，不另加一套。
