# 视觉

手机端在 `src/styles/v3.css`，只作用在 `.v3-app`。暖棕方案已去掉。

三层表面：

| 层 | 色 | 用途 |
|---|---|---|
| `--v3-0` | `#12161c` | 页面底 |
| `--v3-1` | `#1c222b` | 卡片、搜索条 |
| `--v3-2` | `#262e3a` | 芯片、进度槽 |

文字：主色 `#f4f7fb`，辅助 `#9aa3b2`。封面取色用作顶部氛围光、选中芯片和进度。不是纯黑。

字号：页标题 30，区块标题 18，正文 15，辅助 12。卡片圆角 16。图标沿用现有线性图标。页面进入有 0.28 秒上移，底部面板同样有上移。播放时底栏透明度收到 0。
