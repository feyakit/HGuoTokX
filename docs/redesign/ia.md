# 信息架构

手机壳改成暖墨舞台。底部仍是四格，名字不变，避免把原来的入口藏起来：刷剧、剧场、追剧、我的。桌面侧栏保持首页 / 搜索 / 分类 / 我的 / 排行榜 / 设置。

```
刷剧（全屏）
  上下滑换剧，左右滑换 追剧 / 推荐 / 榜单
  看全集 → 剧内连播（上下滑换集，倍速，选集，分享）
  右上搜索 → 剧场
剧场
  搜索、热搜、三块入口（热播榜 / 分类 / 吃瓜）
  轮播、题材芯片、专题、标签
追剧
  继续看、在追、观看历史
我的
  登录、收藏 / 历史
  去设置：缓存、线路、播放、更新、偏好、字幕说明、护眼（外观）、关于
```

## 手势

| 动作 | 结果 |
|---|---|
| 刷剧上下滑 | 换一部剧 |
| 剧内上下滑 | 换集 |
| 左右滑 | 只在刷剧顶栏三个频道之间切 |
| 长按 | 2 倍速，松手恢复 |
| 双击 | 喜欢，不会取消 |
| 点画面 | 控件收起后再点一次叫回来；控件在时点一下暂停 |
| 横屏左右半屏上下滑 | 左亮度，右音量 |

## 取舍

- 评论、画中画、横屏留在原播放页。刷剧流不再叠一套评论面板，热搜和排行仍进那一页。
- 字幕样式和定时关闭在代码里没有独立实现。入口保留，分别落到播放设置和外观，并写明实际能做什么。
- 没有投屏代码，不加假入口。
