# 信息架构

手机底部三栏：首页、发现、我的。桌面侧栏仍是首页 / 搜索 / 分类 / 我的 / 排行榜 / 设置。

```
首页
  全屏刷剧
  顶栏只有「推荐 | 追剧」，左右滑切换
  右上搜索进发现
  播放时底栏跟控件一起淡出
发现
  点搜索框进入全屏搜索（热搜、历史、结果）
  分段「剧集 | 吃瓜」
  剧集：题材芯片直接筛选、榜单（热播 / 推荐 / 潜力）、专辑横滑、按标签找片、信息流
  每个功能一个入口，没有奖杯，没有「打开分类」
我的
  账号卡
  继续观看横滑
  分段「在追 | 收藏 | 历史」
  右上齿轮进设置，页内不再铺设置菜单
```

播放器里完成：选集、评论、倍速、清晰度、线路、横屏、画中画、分享、收藏。热搜、榜单、收藏、历史、专题和标签点进去都进这个全屏剧内播放器。旧播放页还在，桌面继续用，手机主路径不用。

横屏时左侧上下滑调亮度，右侧上下滑调音量。

## 手势

| 动作 | 结果 |
|---|---|
| 首页上下滑 | 换一部剧 |
| 剧内上下滑 | 换集 |
| 左右滑 | 只在推荐和追剧之间切 |
| 长按 | 2 倍速，松手恢复 |
| 双击 | 喜欢 |
| 点画面 | 控件和底栏收起后再点一次叫回来；控件在时点一下暂停 |
