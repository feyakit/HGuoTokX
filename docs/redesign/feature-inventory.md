# 功能清单

以当前代码为准（含 main 上的页面、设置和 Tauri 命令，以及刷剧流）。桌面侧栏不改。手机端新入口写在「新入口」列。`scripts/test-feature-inventory.mjs` 按 `feature-inventory.json` 点这些入口。

投屏：代码里没有。画中画、评论、横屏在原播放页 `Feed`，从搜索、热搜、排行、收藏、历史进去，不在刷剧流里重做一套。

| 功能 | 原入口 | 新入口 | 验证 |
|---|---|---|---|
| 刷剧 | 底部「刷剧」 | 底部「刷剧」，全屏上下滑 | 看到看全集或空状态 |
| 剧内连播 | 看全集 | 看全集 | 出现选集 |
| 静音 | 刷剧左上 | 刷剧左上「静音」 | 按钮在 |
| 搜索 | 剧场搜索框 / 刷剧右上 | 刷剧右上进剧场；剧场搜索框仍在 | 搜索框在 |
| 热搜 | 剧场热搜榜 | 剧场热搜榜，点进原播放页 | 热搜榜区域在 |
| 排行榜 | 剧场奖杯 / 分类页 | 剧场「打开热播榜」，奖杯仍在 | 打开热播榜进入排行 |
| 分类 | 剧场全部分类 | 剧场「打开分类」和「全部分类」 | 打开分类后有返回剧场 |
| 专题 | 剧场专题 | 剧场专题 | 专题页标题 |
| 标签 | 剧场标签 / 题材芯片 | 剧场标签；芯片仍进标签页 | 标签页标题 |
| 吃瓜帖子 | 分类页底部 | 剧场「吃瓜」 | 帖子列表 |
| 追剧 | 底部追剧 | 底部追剧 | 在追 / 观看历史 |
| 收藏与历史 | 我的分段 | 我的「我的收藏 / 观看历史」 | 分段在 |
| 登录 | 我的未登录卡 | 我的「登录」 | 登录框 |
| 离线缓存 | 我的快捷，进整页设置 | 我的「离线缓存」→ 本地数据（清理缓存） | 本地数据设置展开 |
| 线路 | 我的快捷，进整页设置 | 我的「线路设置」→ 网络（播放源、自动选线、诊断） | 网络设置展开 |
| 播放设置 | 我的快捷 | 我的「播放设置」→ 启动静音、优先高清 | 播放设置展开 |
| 字幕样式 | 我的菜单，无独立面板 | 我的「字幕样式」→ 播放设置，并说明跟随系统 | 看到跟随系统这句 |
| 护眼与定时 | 我的菜单，无定时器 | 我的「护眼与定时关闭」→ 外观（深色/浅色/跟随） | 外观设置展开 |
| 内容偏好 | 我的菜单 | 我的「内容偏好」 | 内容偏好设置展开 |
| 检查更新 | 我的快捷 | 我的「检查更新」→ 其他 | 看到检查更新 |
| 关于 | 我的菜单 | 我的「关于 HGuoX」→ 其他 | 看到关于 HGuoX |
| 使用条款 | 设置其他 | 仍在设置「其他」 | 随关于同一屏 |
| 分享 / 喜欢 / 收藏 | 刷剧右侧 | 刷剧右侧 | 分享按钮在 |
| 倍速 | 剧内倍速、长按 2 倍 | 不变 | 剧内有倍速 |
| 亮度音量 | 横屏左右滑 | 不变，竖屏手势说明不写亮度 | 代码仍在 SwipeFeed |
| 评论 / 画中画 / 横屏 | 原播放页右侧和全屏控制 | 从热搜或排行进原播放页 | 热搜能进播放 |
| 主题切换 | 设置外观 | 外观里的跟随 / 浅色 / 深色 | 护眼入口能到 |
| 桌面导航 | 首页 / 搜索 / 分类 / 我的 / 排行榜 / 设置 | 不改 | 本测试只跑手机 |
